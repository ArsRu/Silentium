# Silentium

Silentium — минималистичный приватный live-дистрибутив на базе Arch Linux.

## Что включено
- linux-zen, Sway, Waybar, Alacritty
- Xray, dnscrypt-proxy, nftables, AppArmor, ClamAV
- Обёртка `spacman` для контроля нежелательных пакетов

## Быстрый старт
```bash
priv-setup
vpn-connect
firewall-mode strict
```
